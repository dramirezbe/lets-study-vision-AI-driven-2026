# Student Workspaces

Este directorio está reservado para prácticas individuales de estudiantes.

## Estructura sugerida
- `students/workspaces/<student-id>/module-01/`
- `students/workspaces/<student-id>/module-02/`
- `students/workspaces/<student-id>/module-03/`
- `students/workspaces/<student-id>/module-04/`
- `students/workspaces/<student-id>/module-05/`
- `students/workspaces/<student-id>/module-06/`

Cada carpeta de módulo debe contener:
- código generado vía prompting,
- assets ligeros de prueba,
- resultados de métricas (`latency_ms`, `fps`, `model_size_mb`, `accuracy`).
